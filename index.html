Hermes Mail Fetcher

A private, single-user Gmail read-only tool

What it is

Hermes Mail Fetcher is a personal tool built and used solely by its owner. It runs on the owner's own computer and reads the owner's own Gmail inbox so that new messages can be summarized and delivered to the owner through a personal Telegram bot.

What it is not

This is not a public service. It is not offered to, and cannot be used by, anyone other than the owner. There is no sign-up and no other user accounts.

Access requested

The app requests only the https://www.googleapis.com/auth/gmail.readonly scope. It reads messages and never sends, modifies, labels or deletes any email.
