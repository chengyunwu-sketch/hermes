Privacy Policy — Hermes Mail Fetcher

Last updated: October 16, 2026

1. Who uses this app

Hermes Mail Fetcher is a personal tool used only by its owner, for the owner's own Gmail account. It is not available to the public and does not collect data from any other person.

2. Data accessed

With the owner's authorization, the app uses the Gmail API with the read-only scope (gmail.readonly) to read email messages, including headers (sender, subject, date) and message content, in the owner's own mailbox.

3. How data is used

Email data is used only to filter and summarize the owner's messages and deliver notifications to the owner through the owner's own Telegram bot. The app does not send, modify, label or delete any email.

4. Where data is processed and stored

Processing happens on the owner's personal computer. OAuth tokens are stored locally on that computer. Notifications sent to the owner via Telegram pass through Telegram's service, which the owner uses for personal messaging.

5. Sharing

Data is not sold, rented or shared with any third party, and is not used for advertising or for training models offered to others.

6. Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Locally stored tokens and cached data can be deleted from the owner's computer at any time.
